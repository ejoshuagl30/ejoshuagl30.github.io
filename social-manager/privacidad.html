Política de privacidad

Información sobre el tratamiento de datos al utilizar Social Manager.

Última actualización: 9 de noviembre de 2026

1. Responsable y contacto

Social Manager es una herramienta privada utilizada para gestionar contenido de redes sociales relacionado con la Página Centauros Security Cía. Ltda. Puedes dirigir preguntas sobre el tratamiento de datos a info@centaurossecurity.com.

2. Finalidad del tratamiento

La herramienta permite crear borradores, guardar fotografías y videos, programar publicaciones, conectar cuentas autorizadas y registrar el resultado de los envíos a redes sociales. No ofrece registro público de usuarios.

3. Datos tratados

  • Texto, títulos, archivos multimedia, fechas, redes seleccionadas y estados de las publicaciones.
  • Identificadores y permisos de cuentas y Páginas autorizadas para realizar publicaciones.
  • Tokens y credenciales de integración que hacen posible el acceso autorizado a las API.
  • Datos técnicos de ejecución, resultados y errores que ayudan a operar el sistema y prevenir duplicados.

4. Dónde se procesan

Los datos de trabajo se gestionan mediante una instalación privada de la aplicación, PostgreSQL y n8n. El acceso al panel está limitado a personas autorizadas. Los contenidos autorizados para publicación se remiten a las plataformas externas seleccionadas.

5. Terceros

La publicación en Facebook y, si se configura en el futuro, Instagram, utiliza servicios y API de Meta. Otras plataformas se conectarán únicamente si se configuran y autorizan. Este sitio informativo se aloja en GitHub Pages, sujeto también a las políticas de GitHub.

6. Conservación y eliminación

Los borradores, archivos y registros se conservan mientras sean necesarios para la operación o hasta que la administración los elimine, salvo obligaciones legales aplicables. La eliminación en Social Manager no elimina automáticamente contenidos ya compartidos en plataformas externas.

7. Seguridad

Se utilizan autenticación y controles de acceso privado. Las credenciales no se publican en este sitio. Ningún servicio informático puede garantizar seguridad absoluta.

8. Consultas y solicitudes

Para consultar, corregir o solicitar eliminación de información, escribe a info@centaurossecurity.com. Se podrá comprobar razonablemente la identidad o autorización del solicitante. Consulta las instrucciones de eliminación de datos.

9. Cambios

Esta política podrá actualizarse cuando cambien las funciones de Social Manager, las integraciones o las obligaciones aplicables.
